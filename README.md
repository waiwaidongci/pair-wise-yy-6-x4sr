# 试墨用水准入与签样复核台

由“墨锭试磨室”补建而成，覆盖试墨用水准入、签样判定复核与档案落盘三个业务模块。

## 业务规则

- **每锭一条未结束试墨**：同一墨锭重复或并发提交开试，沿用首次试墨结果（带 `reused` 标记）。
- **水批登记**：须填采集日、余量、浊度；余量不足（少于单次试墨备水）或浊度超过二度时仅转“待换水”，不予开试。
- **签样四要素**：试纸、加水量、出墨速度、墨色层次必填；复核人与试墨人不得相同。
- **复核**：复核通过扣减水批余量并结束试墨；复核退回后沿用同一条试墨重新签样。
- **水批更正**：旧签样立即失效，已结束试墨重开为“试墨中”重测。
- 列表、统计、详情共用同一投影；所有写操作串行化 + 档案原子落盘，刷新后一致。

## 模块划分

- `lib/water.js`：水批校验与准入（纯判定）
- `lib/signoff.js`：试墨生命周期、签样判定与复核、更正失效重测
- `lib/archive.js`：档案原子落盘与事件流水

## 运行

```bash
npm start
```

访问 `http://localhost:3037`。主数据保存在 `data/ink-stick-testing.json`，事件流水在 `data/ink-stick-testing.events.log`。
